- **License**: MIT

## Install

Install the entire collection via `npx skills`:
```bash
npx skills add poorvith-mp/skills-finance
```

Or install individual skills directly:
```bash
npx skills add poorvith-mp/skills-finance --skill <skill-id>
```

For Claude Code plugin marketplace:
```bash
/plugin install poorvith-mp/finance
```
