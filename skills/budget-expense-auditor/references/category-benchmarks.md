# Rough category-share benchmarks (personal budgets)

These are loose reference points for "is this normal," not prescriptive targets — cost of living varies enormously by city and country. Use them only when the user explicitly wants a sanity check against typical spending patterns, and say clearly that these are rough US-centric guides, not universal rules.

| Category | Typical share of take-home income |
|---|---|
| Housing (rent/mortgage) | 25-35% |
| Transportation | 10-15% |
| Food (groceries + dining) | 10-15% |
| Utilities | 5-8% |
| Subscriptions/entertainment | 2-5% |
| Savings/investing | 15-20% (varies widely by goal) |

For business/startup expense audits, there's no equivalent universal benchmark table — compare against the org's own trailing 3-6 month average instead, since "normal" is entirely business-model-dependent.
